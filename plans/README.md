## Findings considered and rejected

Recorded so future audits don't re-litigate them.

### Standard audit (2026-06-11)

- **`callerPlayerId` accepted from request body (reported as IDOR)** — not
  exploitable: `assertCanManage`/`assertCanCreateInvite`
  (`convex/games.ts:222–272`) bind the claimed player ID to a token hash
  the caller must possess; claiming another ID simply fails.
- **canvas-confetti bundle weight** — already code-split via `next/dynamic`
  (`components/poker/game-controller/index.tsx:32`).
- **Players-list memoization / recent-games pagination** — ≤20 items,
  primitive props, stable callbacks; measurable cost is nil.
- **Optimistic-update race conditions in `use-poker-controller.ts`** —
  request-id guards and snapshot signatures are present and correct.
- **`pnpm-workspace.yaml` in a single-package repo** — required by pnpm
  for `onlyBuiltDependencies`; by design.
- **Duplicate non-locale pages (`app/join`, `app/game/[id]`, …)** —
  redirect shims to the default locale; by design.
- **`lints` script ordering / missing `.editorconfig`** — taste.

### Deep incremental audit (2026-06-12)

- **Sileo toast theme "inversion"** (`components/ui/sileo-toaster.tsx:14`)
  — deliberate high-contrast design: toast theme is intentionally the
  opposite of the page theme, consistent in both directions including the
  initial state. Do not "fix".
- **Clipboard empty-catch / deprecated execCommand**
  (`game-controller/index.tsx:100–174`) — strategy fall-through; every
  failure path ends in a user-facing toast; execCommand is the correct
  progressive-enhancement fallback.
- **Session DELETE doesn't revoke backend tokens** — every call site runs
  after the backend already marked membership left/removed; it's cookie
  cleanup, not logout.
- **CSRF on POST routes** — SameSite=Lax cookies are not sent on
  cross-site POSTs; adequate for this threat model.
- **Production browser source maps** — Next.js default is already off;
  finding premise was wrong.
- **`optimizePackageImports` for lucide-react** — in Next's built-in
  default list; @base-ui already uses subpath imports.
- **446 kB shared bundle / 78 kB CSS / critical-CSS inlining / further
  game-page code-splitting** — raw disk bytes (not gzip), no per-route
  first-load measurable; normal for the stack. Re-open only with a real
  bundle-analyzer profile and a target metric.
- **`getStatusLabel` not exhaustive** — it's typed `Record<Status, string>`;
  already compiler-enforced.
- **Error boundary doesn't reset on navigation** — only reachable via
  game→game soft navigation which doesn't occur in practice (home page in
  between unmounts it); Retry does a full reload. Theoretical.
- **Auto-reveal switch missing aria-label** (also TODO.md) — already
  satisfied: `Label htmlFor` → Base UI Switch button id association
  provides the accessible name. Plan 006 removes the stale TODO entry.
- **`/xx/` invalid locale paths** — proxy.ts redirects non-locale paths;
  unreachable. By design.
- **`withLocale` double-prefix / `normalizeUrl` protocol-relative input**
  — not triggered by any call site; misconfiguration-only. Hardening not
  scheduled.
- **Convex client throws when `NEXT_PUBLIC_CONVEX_URL` missing /
  module-level env reads / structural ConvexError parsing /
  `console.error` in the error boundary** — by-design fail-fast or
  standard practice.
